# Bounded Gemma4 RoPE / KV 2×2 experiment

This opt-in debug harness leaves production wrappers, registrations and exporter
passes unchanged. See [WrapQ](../../../wrapq/README.md),
[recipe export](../../export/README.md) and [development](../../../../../docs/development.md)
for lifecycle, serialized-domain and tooling contracts.

Run from the repository root with the configured virtual environment:

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m \
  tico.quantization.recipes.debug.rope_kv_experiment.runner \
  --output /tmp/rope-kv-run
python -m tico.quantization.recipes.debug.rope_kv_experiment.report \
  --input /tmp/rope-kv-run --output /tmp/rope-kv-report
```

The default sequential run covers both profiles, seeds 123/456/789, four freshly
calibrated variants, 8-token prefill and 128 own-cache decode steps (including a
32-step checkpoint). Each variant saves/reloads prefill and decode Circle files;
FAKE_QUANTIZE recurrent execution appends the Circle's S delta bytes. NATIVE is
attempted independently. `--variant R1K1 --profile u8s16c --seed 456 --steps 32`
reruns a subset; reports require complete four-way comparisons for selected groups.
Output directories must be new. `--no-circle` explicitly records NOT_RUN.

`affine` follows smoke's UINT8 per-tensor activations and UINT8 per-channel weight
policy. `u8s16c` changes activations/compute to INT16 per-tensor symmetric while
retaining UINT8 storage and the same weight policy. No GPTQ or rotation is used.
Models have real HF Gemma4 attention implementations, smoke tiny geometry
(hidden 64, two Q/KV heads, head dimension 32), random weights and no LM head.
These metrics measure local attention error, not pretrained language quality.
Inputs are deterministic Gaussian hidden traces with consistent analytic RoPE;
they are independent of the attention output, as in an attention replay.
Full-model hidden feedback and token-level teacher forcing require a real model.

## Policies and controls

| Variant | RoPE split/reorder | KV current | KV past |
|---|---|---|---|
| R0K0 | independent half/cat observers | F_C(F_S(r)) | F_C(F_P(p_S)) |
| R1K0 | inherit Q/K norm domains independently | F_C(F_S(r)) | F_C(F_P(p_S)) |
| R0K1 | independent half/cat observers | F_C(r) | F_C(p_S) |
| R1K1 | inherit Q/K norm domains independently | F_C(r) | F_C(p_S) |

Every variant emits F_S(r); only this delta is appended to persistent storage.
K0 concat is C/C→C, exactly as K1. R1 applies only to pre-negated sine with
per-tensor affine sites. Norm collection remains at the original location;
annotation-only frozen fake quantization inherits the source domain, and the
ordinary exporter folds redundant boundaries. Arithmetic cos/sin/rotation sites
are unchanged. HF, per-channel and MX retain their prior supported behavior.
P observers copy S policy before preparation but collect independently from actual
cache reads. Production legacy checkpoint guards remain active. Experimental
state includes the policy identity and rejects cross-variant restoration.

Each group calibrates three separate streams of 8-token prefill + four actual
cached decode reads. CALIB passes FP values through, as standard WrapQ does;
its cache is generated by prefill, not randomly fabricated. Evaluation streams
use disjoint IDs. `config.json` records stream IDs, token counts, geometry and FP
state hash; `calibration.json` records effective calls and ranges.
`observers.json` records grids, origin and frozen fingerprints including dormant
sites. Common calibration sites naturally retain identical qparams here because
CALIB does not execute fake quantization. Same storage dtype alone is never used
as evidence for equal scales/zero-points.

An independently instantiated original production wrapper is calibrated separately.
R0K1 must exactly match eager outputs, attention weights, deltas, grids and saved
operator/ABI topology. Only the known experimental class qualification in debug
tensor names is normalized. Original HF code with DynamicCache independently
checks NO_QUANT prefill/decode parity before quantized error is measured.
State hashes cover weights, observers and nonpersistent buffers before/after
export and evaluation. Focused tests cover sliding eviction and shared producers.

## Evidence and interpretation

`result.json` separates FP-vs-quantized quality, same-input eager-vs-Circle fidelity,
FP-cache reinjection replay, and own-S-cache rollout. The original FP reference
uses its original hidden inputs and own FP cache. Static decode has a valid prefix,
right padding excluded by mask, current at the final slot, and absolute RoPE
positions. Serialized S output/input grids are checked before byte reuse.

The frozen replay imports calibrated common grids using public `load_qparams`
**before** freeze, holds common S past bytes fixed, and compares against both a
local FP reference with the same dequantized S past and the original FP cache.
R0 half/cat and K0 P grids come from that same FP calibration material.
It includes two small R0 intermediate K policies to separate past-P removal from
current-S bypass; neither modifies the frozen state during execution.

Tensor metrics include MAE, RMSE, max absolute error, relative L2 and cosine.
Relative L2 denominator is max(reference L2, 1e-12); near-zero cosine rules are
recorded in the helper. PEIR is max error / reference range (constant range uses
1), dimensionless. Clipping counts pre-round codes outside [qmin,qmax], separately
from rounded/clamped endpoint occupancy. Past/current/concat errors are separate;
eager traces contain valid tokens only. Equal-S integer code mismatch is diagnostic
only and is unavailable for numerically different S grids.

Circle records include full serialized operator edges/options, tensor grids and
ABI, Quantize counts by structural region, consecutive Quantize pairs, and concat
legality. `COMPLETED` means measurements exist; `validation_status` is separate.
Missing/empty/nonfinite execution evidence cannot pass. The strict fidelity check
uses atol=1e-5, rtol=1e-4 without increasing tolerances on failure. Native integer
arithmetic support, fake-quantize reference execution and NPU validation are distinct.
Quantize counts do not establish latency improvement.

Pretrained cached NLL/PPL is ASSET_UNAVAILABLE when no checkpoint/text exists.
The metric helper tests target alignment and exact valid-token sums, but this
attention harness does not implement whole-model pretrained loading/evaluation.
For a follow-up, first supply local Gemma4 weights/tokenizer and disjoint text,
then integrate this adapter with the existing Gemma4 recipe's real cached path;
`examples/configs/gemma4_quantize.yaml` is the W4A16 policy starting point.
Do not use the existing uncached PPL recipe as KV-policy evidence or infer
pretrained accuracy from random tiny outputs.
